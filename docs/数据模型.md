# 数据模型

承自《梦之城综合教学平台设计方案 V1.1》§4，代码在 `packages/server/src/db/`。

- `schema.ts` —— drizzle ORM 定义（类型化查询）
- `migrations/0001_init.sql` —— 手写迁移（可读、可审）
- 两者的一致性由 `npm run check:constraints` 的 **S1** 检查保证（表名与列名逐一比对）

---

## 三层分离

```
模板层  level → unit → lesson → lesson_plan_version      课程内容（可修订）
实例层  lesson + plan_version → class_session → session_activity → session_record
                                                  → observation                课堂执行
价值层  guardian → student → enrollment → artifact / assessment / feedback
        guardian → student → showcase / peer_note / visibility_grant / consent
```

**为什么必须拆**：`lesson` 是教案模板，会被修订成 v1.1、v1.2；
`class_session` 是一次真实上课，永远指向**当时**那个版本快照。
不拆的话，改一次细案，往期课堂记录全对不上（硬约束 C5）。

## 表清单

### 模板层

| 表 | 关键字段 | 说明 |
|---|---|---|
| `level` | `id`（`GRADE_L1/L2/L3`）、`code`、`name`、`grade_range`、`theme`、`seq`、`goals` | 三个级别主数据 |
| `unit` | `id`、`level_id`、`seq`、`name` | 每级 4 个单元，边界 1–4 / 5–8 / 9–12 / 13–16 |
| `lesson` | `id`（`L1-01`…`L3-16`）、`unit_id`、`level_id`、`seq`、`title`、`output`、`default_recipe`、`current_version_id` | 48 节课模板 |
| `lesson_plan_version` | `id`、`lesson_id`、`version`、`content_json`、`note`、`created_by`、`created_at` | 教案版本快照，**只增不改** |
| `activity_plugin` | `id`、`name`、`version`、`entry`、`manifest_json`、`result_schema`、`enabled` | 活动插件注册表 |

`lesson_plan_version.content_json` 里装的是细案十字段 + 五环节 + `totalMinutes` + `canonicalMinutes`。

> **单元名从哪来**：单元边界按每级 16 节均分成 4 组（1–4 / 5–8 / 9–12 / 13–16），
> 单元名从该单元 4 节课的真实主题归纳（L1：认识 AI / AI 动手创作 / 钱的秘密 / 模拟市集），
> **不新增课程内容**。抽取逻辑见 `tools/extract-lessons.py` 的 `UNIT_NAMES`。

### 实例层

| 表 | 关键字段 | 说明 |
|---|---|---|
| `staff_user` | `id`、`email`、`name`、`role`（TEACHER/OPS/ADMIN）、`password_hash` | 讲师等员工账号（scrypt） |
| `class_session` | `id`、`lesson_id`、`plan_version_id`、`term_id`、`class_code`、`teacher_id`、`class_type`、`participant_count`、`state`、`started_at`、`ended_at` | **数据模型的主键** |
| `class_session_participant` | `session_id`、`student_id`、`joined_at`、`left_at` | 课堂名单 |
| `session_activity` | `session_id`、`seq`、`phase`、`mode_card`、`atom`、`title`、`duration_min`、`plugin_id`、`resource_id`、`activity_kind` | 课堂编排的最小颗粒 |
| `session_record` | `session_id`、`session_activity_id`、`record_type`、`student_id`、`actual_min`、`event_json`、`occurred_at` | 环节实耗与切换事件 |
| `observation` | `session_id`、`student_id`、`speak_count`、`patrol_count`、`stuck_count`、`task_completion` | 手册 8.1 的六指标 |

`class_session` 上有 `CHECK (participant_count >= 2)` —— 班型下限 ≥2 人，不设计 1 对 1。

### 价值层

| 表 | 关键字段 | 说明 |
|---|---|---|
| `guardian` | `id`、`phone`、`name`、`sms_verified_at` | 家长账号，**唯一登录主体** |
| `student` | `id`、`guardian_id`、`display_name`、`avatar_key`、`avatar_stage`、`grade`、`level_id`、`badge`、`state` | 学员子身份（无密码） |
| `term` | `id`、`name`、`level_id`、`start_date`、`end_date`、`status` | 期次 |
| `enrollment` | `student_id`、`term_id`、`package_type`、`total_lessons`、`used_lessons`、`price`、`status` | 报读与课消 |
| `artifact` | `session_id`、`student_id`、`lesson_id`、`artifact_type`、`title`、`content_json`、`visibility`、`wall_approved` | 学生产出，家长可见物 |
| `artifact_view` | `artifact_id`、`viewer_student_id`、`viewer_guardian_id`、`relation`、`viewed_at` | 「谁看过」 |
| `showcase` | `student_id`、`session_id`、`artifact_id`、`title`、`visibility`、`wall_approved` | 展位条目 |
| `peer_note` | `showcase_id`、`from_student_id`、`note_type`、`content`、`review_state` | 跨期正向留言（三类句式） |
| `visibility_grant` | `guardian_id`、`student_id`、`scope`、`artifact_id`、`granted_at`、`revoked_at` | 授权留痕，**逐件可撤回** |
| `consent` | `guardian_id`、`student_id`、`scope`、`granted_at`、`revoked_at` | 知情同意，可撤回 |
| `student_feedback` | `session_id`、`student_id`、`content`、`teacher_comment`、`next_step`、`sent_at` | 每 4 节反馈 + 结课摘要 |

## 学生身份怎么来的（注册 → 当堂登录 → 使用）

**不做开放注册**（硬约束 N2，有自动化检查）。学员身份只能由监护人创建：

```
① 家长手机号 + 短信验证码登录
   └─ 手机号未登记时自动建一份空档案（不采集额外个人信息）

② 家长端「添加孩子」
   ├─ 昵称（≤10 字，不写真实姓名）
   ├─ 年级 3–9
   ├─ 头像（12 个几何头像 × 3 个装备阶段，SVG 现画，零图片请求）
   └─ 知情同意四项逐项勾选 → 写 consent 表
      作品上墙 / 影像 / 数据 / 跨期 —— 未勾选的记为「未授权」（revoked_at 非空）
      每一项随时可撤回

③ 讲师端「学员名册」/ 驾驶舱点名
   └─ 把孩子加入本次课的名单（class_session_participant）
      试听与插班也走这条路

④ 学生端课堂码进入
   ├─ 命中名单 → 点头像 → 拿到短时效课堂令牌（不设密码、不产生长期身份）
   └─ 没命中 → 明确提示「还没被排进这节课，让老师把你加进来」
      而不是笼统的「课堂码不对」

⑤ 当堂使用
   ├─ 参与活动、提交作品 → 落 artifact + showcase
   ├─ 同班作品墙、给同伴留三类句式留言
   └─ 我的展位（人人有份、按时间排序、不显示任何数字）

⑥ 家长端回看
   └─ 作品墙时间线、成长档案、收到的每一条留言
```

### 相关接口

| 接口 | 身份 | 作用 |
|---|---|---|
| `POST /api/guardian/children` | 家长 | 注册孩子（含知情同意逐项记录） |
| `POST /api/guardian/children/:id/consents` | 家长 | 撤回 / 补上某一项同意 |
| `GET /api/students` | 讲师 | 学员名册（可按名字/家长/手机号后四位搜） |
| `POST /api/sessions/:id/participants` | 讲师 | 点名进班 |
| `DELETE /api/sessions/:id/participants/:studentId` | 讲师 | 移出本班 |
| `POST /api/auth/student/pick` | — | 课堂码 + 选头像 → 课堂令牌 |

`consent` 表在设计方案的表清单里是「知情同意留痕」，
本项目把它真正用起来了 —— **它是监护人同意的证据，不是装饰**。

## 与设计方案 §4.1 的两处差异

设计方案的表清单里有两处在本项目里做了合并/改名，这里写清楚，避免对不上：

### 1. `student` 与 `student_identity` 合并

设计方案列了两张表：

```
student         (id, guardian_id, nickname, avatar_stage, grade, level_id, state)
student_identity(id, student_id, display_name, avatar_key, level_stage, badge_json)
```

两张表的字段高度重叠，拆开只会制造同步 bug（改昵称要写两处，忘了就穿帮）。
**本项目合并为 `student` 一张表**，字段取两者的并集。

### 2. `activity` 改名 `session_activity`

设计方案里 `activity` 是「课堂编排的最小颗粒」，而 `activity_plugin` 是「可插拔活动注册表」。
两个都叫 activity，读代码时容易把「插件」和「这次课上的第几个环节」搞混。
**本项目把前者改名为 `session_activity`**，语义一眼可辨。

## 可见范围怎么算

四级范围，**服务端强制过滤**（硬约束 C7），越权一律返回 **404**（不泄露资源存在性）。

| 层级 | 谁能看 | 默认 | 授权方式 |
|---|---|---|---|
| `VIS_L0` 私密 | 本人 / 讲师 / 家长 | ✅ | 无需授权 |
| `VIS_L1` 本班 | 同期班学员与家长 | 需勾选 | 报名时一次授权 |
| `VIS_L2` 跨期 | 本校区在读与结业学员及家长 | 需二次授权 | 家长单独同意 + 逐件 grant |
| `VIS_L3` 对外 | 公开链接 / 分享海报 | 需逐件授权 | 逐件 + 水印 + 可撤回 |

判定逻辑在 `packages/server/src/modules/visibility/service.ts`：

1. `visibleScopesFor(viewer, studentId)` —— 算出 viewer 对该学生能看���哪些范围
2. `canViewArtifact(viewer, ctx)` —— 范围够不够 + 有没有对应的未撤回 grant
3. `assertCanViewArtifact(...)` —— 不够就抛 `NotFoundError`（404）

「同班」的判定：共享同一期次（`enrollment.term_id`）或共享至少一次课堂会话。

## 为什么没有这些字段

| 字段 | 为什么没有 |
|---|---|
| `like_count` / `view_count` / `rank` / `popularity` | L1 第 16 节课写了「不以营收排名，按敢讲、算得清、会复盘结业」。一旦有量化人气指标，孩子会迅速学会做「容易获赞」的作品。**产品机制不能和课程价值观打架**。 |
| `student.password` | 课堂码是当堂失效的会话凭证，不产生长期身份；8 岁孩子不应记密码。 |
| `price` 的默认值 | 按 ≥2 人小班重定报价尚未拍板，存 `NULL`，界面显示「待定」，不沿用旧价也不自行推算。 |

「谁看过」用 `artifact_view` 的**行**表达（一行一次访问，只记人与关系），
而不是一个计数字段 —— 这样既能满足「孩子能看到谁看过」，又不会产生数字。
