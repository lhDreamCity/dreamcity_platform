## 别踩这些坑

| 坑 | 说明 |
|---|---|
| **`.env` 里出现重复的 `SMS_*` 行** | 后面的覆盖前面的 → 「我改了怎么没生效」。写之前先 `sed -i '/^[[:space:]]*SMS_/d' .env` |
| **以为「营销签名」能发验证码** | 腾讯云要求签名类型与模板类型一致。营销签名只能配推广模板 |
| **腾讯云官网被网络策略挡** | 本机取不到 `cloud.tencent.com`，改用搜索确认规则 |
| **本机没有 bash / Docker / WSL** | shell 脚本无法本地验证 → 部署前的检查逻辑写成 `deploy/check-env.mjs`（Node，可测） |
| **改私有后匿名 API 读不到 Actions** | 用 `node tools/ci-status.mjs --jobs` |
| **别动同机的官网与 workbench** | `lhdreamcity.com` 与 `work.lhdreamcity.com` 是另外两个项目 |

## 关键决策（别推翻，也别忘了）

| 决策 | 内容 |
|---|---|
| 部署方向 | **Actions 推包到服务器**，不是服务器去拉 —— 服务器连不上 github.com（实测 20 秒超时），但连 gitee.com 1.6 秒 |
| 3D 的位置 | 进活动层不进平台层；原生 WebGL 手写渲染（不引 three.js），无 WebGL 自动降级 2D |
| 学员身份 | 课堂码 + 头像选择，无密码无手机号；**只能由监护人创建**（硬约束 N2，有自动化检查） |
| 后台入口 | 隐藏 URL `/console` + 账号密码双闸；落地页只有家长与学生两个入口 |
| 期次/报名 | **故意没做** —— 班级成员由讲师点名点出来 |
| 短信失败处理 | 发送成功才写缓存；失败返回 502 并把腾讯云错误码记进日志 |
| 短信配置缺失 | `SMS_DRIVER=tencent` 但缺项 → **拒绝启动**（缺项比不配更危险） |
