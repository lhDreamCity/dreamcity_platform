## 3. 与文档描述的核对（重要）

文档称 L1=绘本探险/贴纸卡（粗描边+实心硬阴影）、L2=探索实验室/细边白卡、L3=少年发布会/深空玻璃卡。**实测不支持这套分级表面语言**：

- 三份纲要 PPT 是**同一模板**（形状名、坐标、`adj` 圆角、`a:ln w=` 描边宽度、阴影参数逐项一致），差异**只有主色与次色两组十六进制值**（L1 蓝 / L2 紫 / L3 橙）。
- 全部 6 份 PPT 只有**一种阴影**：`outerShdw blurRad="140000" dist="50000" dir="5400000"`，色 `0B1B2C` **alpha 22%**（软阴影）。**没有实心硬阴影、没有粗描边**。描边只有 0.7 / 0.8 / 1.0 / 2.2 pt 四档。
- **深空玻璃感不属于 L3**：深空星空背景图在 L1/L2/L3 全部存在，用于课件的第 5（先想一想）、9（关键提问）、12（实操进行中）页，以及纲要的第 1/2/11/14 页。
- 真正的级别差异只有三处：① 主色/次色；② 吉祥物着色；③ 编号圆点徽章的取色轮转。

## 4. 吉祥物「小梦」

- **不是 SVG，是位图 PNG**：`ppt/media/image2.png`，**800×1000 RGBA**，透明背景（不透明像素 354,500 / 800,000 = 44%），带 alpha 边缘；同一几何稿按级别重新着色（3 个 PNG，形状完全相同，仅主色不同）。
- 造型：Q 版机器人，白色头/身外壳 + 主色描边，深藏青面屏 `#0F2847`，大白眼 + 主色虹膜，**黄星 `#FFD84D` 印在胸口**，青色 `#22D3EE` 微笑弧线，腮红深红，顶部一根天线 + 黄色天线球，深色椭圆投影。
- 分级着色（L1 蓝 / L2 紫 / L3 橙）：主体色占比 9.3%，白 8.0%，`#2C5E9B` 深蓝 3.0%，`#FFD84D` 2.8%（L2 少 1.9% 并多 `#22D3EE` 1.3%），身体渐变 `#26B6F1`→主色。
- 出现位置：
  - 纲要 PPT：第 1 页（封面，右下）、第 11 页（旗舰项目）、第 14 页（结尾）—— 均为深空背景页。
  - 课件 PPT：第 1 页（封面）、第 5、9、12 页（深空反思页）。
- 摆放方式：PNG 叠在 3–4 个同心椭圆“气泡”之上（主色实心圆 + 主色/次色圆 + 白色高光椭圆 + 次色 2.2pt 描边弧形椭圆），封面 PNG 尺寸 3.35×4.19 in，反思页 2.1×2.62 in。

### 7.2 阴影（全站唯一规格）

```
outerShdw blurRad="140000" dist="50000" dir="5400000" rotWithShape="0"
  color #0B1B2C, alpha 22%
```
→ 模糊 0.153 in（3.9 mm / 11 pt）、下移 0.055 in（1.4 mm / 4 pt）、纯垂直向下。Web 等价：`box-shadow: 0 4px 11px rgba(11,27,44,0.22)`。

### 7.3 描边宽度档位

0.7pt（课件巡回条）· 0.8pt（表格行 / 小结卡 / 深底按钮）· **1.0pt（主卡片与表格行，主用档）** · 2.2pt（封面气泡弧线，唯一一处彩色粗描边）。

## 8. 一句话设计系统摘要

`#FFFFFF` 卡 + `#DCE9F1` 1pt 描边 + 22% 软阴影 + 6–16px 圆角 + 微软雅黑 9.5–41pt 阶梯 + 一个级别主色（蓝 `#2E7CF6` / 紫 `#7C6BFF` / 橙 `#F2A33C`）+ 一个次色（青 `#22D3EE` / 蓝 `#2E7CF6` / 珊瑚 `#FF7A6B`）+ 胶囊 chip + 圆形编号徽章 + 深空/浅点阵双背景 + 800×1000 透明 PNG 机器人「小梦」。
