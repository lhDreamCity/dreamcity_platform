# 梦之城综合教学平台 · Classroom OS

> **这个平台不是「在线学习平台」（LMS），是「课堂操作系统」——第一用户是讲师，第一产出不是课程录像，而是可复用的课堂编排与家长看得见的成长证据。**
> 它服务线下 90 分钟，不把线下搬到线上。

深圳领航梦之城科技有限公司 · 梦之城 AI 赋能中心

---

## 这份代码要守住什么

平台的设计不是从功能清单来的，是从几条业务红线反推出来的：

| 红线 | 在代码里的落点 |
|---|---|
| **溢价来自 M5 个别点拨与 M6 对外输出里的真人追问** | `MODE_M5` / `MODE_M6` 标 `teacherOnly: true`；不做录播主线 |
| **讲师一节课手工录入 ≤ 3 次点击** | 环节实耗由服务端按时间戳自动算；开口次数用点击代替画正字 |
| **课堂网络与投屏机比 GPU 更可能毁掉一节课** | 活动是单文件 HTML、零 CDN、零后端请求；无 WebGL 自动降级 2D；断网可续玩、结果本地缓存后补传 |
| **课件会被抄，编排抄不走** | `lesson` 与 `class_session` 拆表；教案版本只增不改；模式卡序列是一等数据 |
| **孩子需要「被看见」，但不是被排名** | 四级可见范围服务端强制过滤；表里没有任何人气字段；跨期留言只准三类句式 |
| **产品机制不能和课程价值观打架** | L1 第 16 节课写了「不以营收排名」→ 平台不给点赞数、不给排行榜、不给信息流 |
| **未定稿的商业数据不编造** | 报价、开班日期、课包档位一律 `NULL`，界面显示「待定」 |

这 13 条在《开发上下文》第 8 章里逐条列成了硬约束 C1–C13。
**每一条都有对应的自动化检查**：`npm run check:constraints` 会真的跑一遍并拦下问题。

## 快速开始

```bash
npm install

npm run db:migrate     # 建库（PGlite，免安装）
npm run seed           # 48 节课入库 + 演示班级
npm run dev            # 后端 :8787 + 前端 :5173
```

打开 http://localhost:5173

> Vite 8 默认只监听 IPv6 的 `localhost`，用 `127.0.0.1` 访问会连不上 —— 用 `localhost` 即可。

| 入口 | 地址 | 演示账号 |
|---|---|---|
| 家长 | `/guardian/login` | 手机号 `13800000001`，验证码 `00000`（开发模式） |
| 学生 | `/student/enter` | 课堂码进入后点头像，不用密码 |
| 后台（讲师 / 运营） | `/console` | `admin` / `123456`（开发占位，见下） |

> **后台是隐藏入口**：落地页只给家长和学生两个按钮，讲师后台的地址不出现在页面上，
> 要自己敲 `/console` 进来，进来还得过账号密码这一关。
> 真实讲师账号用 `npm run create:teacher` 建（邮箱 + 密码）。
> 占位账号由 `ADMIN_USER` / `ADMIN_PASSWORD` 控制（默认 `admin` / `123456`），
> 改 env 立刻生效；`ADMIN_ENABLED=false` 则彻底关掉这个账号。

> ⚠️ **PGlite 是单进程数据库**：`npm run seed` 之前要先停掉后端，
> 否则两个进程会同时写同一个数据目录把库写坏。生产用真 PostgreSQL 时没有这个限制。

### 视觉分层的原则

**孩子端活泼，家长端克制。** 吉祥物「小梦」只出现在学生端（当堂、我的展位）；
面向家长与讲师的界面（落地页、顶栏、两个登录页）用文字与色块，不用卡通形象 ——
全卡通会把客单价的心理锚点拉低。

### 上云

代码侧已具备上云条件：单体一台机、一次部署、前端由后端托管、
生产配置缺项直接拒绝启动、安全头 / CORS / 限流 / 优雅关闭齐备。

```bash
npm run build && npm start   # 生产启动（NODE_ENV=production）
```

完整的 Nginx 配置、systemd 单元、环境变量清单与上线检查清单见
**[`docs/部署.md`](docs/部署.md)**。

## 三端在做什么

### 讲师端 —— 一屏三区

```
┌─────────────┬───────────────────────────┬──────────────┐
│ 90 分钟时间轴 │ 投屏 / 控制                │ 名单与采集    │
│              │                           │              │
│ 导入 10′ 实耗9′│  iframe 活动 / 课件页      │ 小宇 已问×2   │
│ 讲解 20′ 实耗21′│  计时器 · 下一环节预览      │ 然然 还没问    │
│ 实操 35′ 进行中 │  断网兜底提示              │              │
│ 展示 15′      │                           │ [完成][卡住] │
│ 收尾 10′      │  活动序列（可拉起）         │ [已单独问过]  │
└─────────────┴───────────────────────────┴──────────────┘
```

- **实耗自动累计** —— 点一下环节，时间轴自己算，讲师不用记
- **三个按钮，只点不填** —— 点击自动带时间戳与当前环节
- **一键结课** —— 冻结会话、课堂码立刻失效、生成结课摘要草稿

### 家长端 —— 时间线，不是功能宫格

打开 3 秒内看到：孩子这节课做出了什么 → 老师一句话点评 → 剩余课时。
另有成长档案、每 4 节反馈、可见范围授权开关（全量数据可导出、可注销）。

### 学生端 —— 最薄的一端

课堂码 → 点一下头像（没有密码框、没有手机号）→ 参与活动 → 提交作品 → 看自己的展位。
展位人人有份，按时间排不按优劣；能看到「谁看过、谁留了什么话」，**但不显示任何数字**。

### 学生身份怎么来的（不做开放注册）

学员身份**只能由监护人创建**（硬约束 N2，有自动化检查）：

```
家长手机号 + 短信验证码登录 → 「添加孩子」（昵称 · 年级 · 头像 · 知情同意逐项勾选）
  → 讲师名册里出现这个孩子 → 课堂点名进班 → 学生用课堂码点头像进入 → 当堂使用 → 家长端看到
```

没被排进这节课时，孩子看到的不是「课堂码不对」，而是「**还没被排进来，让老师把你加进来**」。

## 活动插件

活动 = 独立单文件 HTML + 一份 manifest，通过 `postMessage` 回传结果。

```
驾驶舱 (host)  ──iframe──>  活动 HTML（零 CDN · 零后端请求）
     │                              │
     │  dreamcity:host:init         │  dreamcity:activity:result
     │  （注入 sessionId/studentId） │  （回传 payload）
     ▼                              ▼
  宿主落库 → artifact + showcase   （断网时进本地队列，恢复后补传）
```

已内置三个：

| 插件 | 对应课次 | 教学内核 |
|---|---|---|
| 柠檬水摊大作战 | L1-10 / L1-13 / L2-10 / L3-13 | 定价、成本、利润、甜蜜点（90 秒经营） |
| 提示词闯关 | L1-04 / L2-04 / L3-03 | 角色 · 任务 · 格式 三段式 |
| 太阳系变量实验室（2D） | L1-02 / L2-01 / L3-01 | 导入 → 预测 → 实验 → 记录 → 收尾 |
| 太阳系变量实验室（3D） | 同上 | 同一套教学逻辑，WebGL 渲染，投屏机不支持时自动降级到 2D |

教研以后加课眼不用等研发排期：写一个单文件 HTML + manifest，
`POST /api/plugins` 校验通过即可上架。详见 `docs/插件规范.md`。

## 验证

```bash
npm run verify              # typecheck + 单元测试 + 硬约束检查
npm test                    # 31 个单元测试
npm run check:constraints   # C1–C13 + 命名纪律 + schema 一致性（15 项）

```

`tools/smoke-test.mjs` 走一遍真实链路：讲师登录 → 建课 → 开课拿课堂码 →
学生用码进入 → 驾驶舱推进环节 → 三键采集 → 插件回传落库 → 结课使课堂码失效 →
家长登录看到作品墙 → 越权访问返回 404。

## 明确不做

录播课 · 直播课 · 独立 App · 开放注册 · 私信 / 关注 / 粉丝 · 点赞计数与人气榜 ·
公开可检索 · 无限滚动信息流 · 题库刷题与自动排名 · AI 自动评分替代教师评价 ·
全站 3D/WebGL（活动内部的 3D 渲染除外，站点界面本身不做 3D）· 自建视频转码 ·
自建 IM 与社群 · 复杂权限矩阵与多租户 · 在线支付。
